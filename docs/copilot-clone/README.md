# Kaspit (כספית) — Copilot Money clone for Israel

This folder contains the product & engineering plan for **Kaspit**, a SwiftUI
personal-finance app for the Israeli market, feature-matched to Copilot Money
(dashboard, review workflow, learning categorization, budgets with rollover,
recurrings, investments, net worth, cash flow, goals, rules engine).

- **[PLAN.he.md](./PLAN.he.md)** — the full plan, written in Hebrew.
- App source lives in [`/Kaspit`](../../Kaspit).
